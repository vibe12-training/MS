# 3학년 퀴즈 만들기

초등학교 3학년 수업용 4지선다 퀴즈 생성기입니다. 교사가 교과·단원·난이도를 고르면 문항 5개를 카드로 보여 줍니다. 로그인은 없습니다.

## 실행

Node.js 22.9 이상이 필요하고, 따로 설치할 패키지는 없습니다.

```
npm start
```

브라우저에서 <http://127.0.0.1:3000> 을 엽니다. PowerShell에서 `npm`이 실행 정책 오류를 내면 `npm.cmd start` 또는 `node server.js`로 실행합니다.

기본 설정에서는 이 컴퓨터에서만 접속할 수 있습니다. 주소와 포트는 `HOST`, `PORT` 환경 변수로 바꿉니다.

## 문항이 만들어지는 방식

| 상황 | 문항 출처 |
| --- | --- |
| AI 키 미설정 (기본) | 내장 문제은행 |
| AI 키 설정 | AI 생성 |
| AI 키 설정 + 생성 실패 | 내장 문제은행으로 대신 만들고 화면에 알림 |

- **수학**은 저장된 문항이 아니라 매번 새 숫자로 계산해서 만들므로 누를 때마다 다른 문제가 나옵니다.
- **국어·사회·과학**은 단원·난이도마다 5~6문항이 저장되어 있어, 다시 만들어도 대부분 같은 문항이 순서만 바뀌어 나옵니다.
- AI가 만든 문항은 형식(문항 5개, 서로 다른 선택지 4개, 정답 위치)만 자동으로 검사합니다. **내용이 맞는지는 검사하지 못하므로 수업 전에 직접 확인해야 합니다.**

## AI 연결 (선택)

OpenAI 호환 Chat Completions API를 쓰는 서비스에 연결할 수 있습니다. `.env.example`을 `.env`로 복사한 뒤 값을 채우고 다시 실행합니다.

| 변수 | 설명 |
| --- | --- |
| `AI_API_KEY` | API 키 |
| `AI_MODEL` | 모델 이름 (Azure는 배포 이름) |
| `AI_BASE_URL` | 생략하면 `https://api.openai.com/v1`. Azure AI Foundry는 `https://리소스이름.openai.azure.com/openai/v1` |

`AI_API_KEY`와 `AI_MODEL`이 모두 있어야 AI 생성이 켜집니다. 키는 서버에서만 쓰이고 브라우저로 전달되지 않습니다. `.env`는 `.gitignore`에 들어 있습니다.

## 단원과 문항 고치기

- 화면의 교과·단원·난이도 목록: `src/curriculum.js`. `label`은 학교 교과서에 맞게 바꿔도 되고, `id`는 문제은행과 연결되므로 그대로 둡니다.
- 국어·사회·과학 문항: `src/bank/korean.js`, `social.js`, `science.js`. 한 문항은 `[문제, 정답, [오답 3개], 해설]` 형식이며, 단원·난이도마다 5개 이상 있어야 합니다.
- 수학 문항 생성 규칙: `src/bank/math.js`.

문항을 고친 뒤에는 `npm test`로 모든 단원·난이도에서 문항 5개가 올바른 형식으로 만들어지는지 확인할 수 있습니다.

## 구성

```
server.js            웹 서버 (정적 파일, /api/meta, /api/quiz)
src/curriculum.js    교과·단원·난이도 목록
src/generate.js      입력 확인, AI 또는 문제은행 선택
src/ai.js            AI 호출과 응답 검증
src/bank/            내장 문제은행
public/              화면 (HTML, CSS, JS)
test/                테스트
```
